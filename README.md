## 🏭 Система «AgroControl»

Разработана **автоматизированная система управления технологическим процессом** производства средств защиты растений (гербициды, инсектициды, фунгициды).

### 🔧 Модули системы

| Модуль | Назначение |
|--------|------------|
| **AgroControl.API** | Бэкенд-сервер, обеспечивающий хранение данных, бизнес-логику и REST API |
| **AgroControl.Technologist** | Рабочее место технолога – управление продукцией, рецептурами, техкартами, заказами, партиями, отчётами |
| **AgroControl.Laboratory** | Рабочее место лаборанта – контроль качества сырья и готовой продукции, ведение испытаний, принятие лабораторных решений |
| **AgroControl.Operator** | Рабочее место аппаратчика – выполнение шагов техкарты, ввод фактических параметров, фиксация отклонений, мониторинг экструдера в реальном времени |

### ⚙️ Ключевые функции

- 🔐 Авторизация с капчей (для всех ролей)
- 📊 Управление рецептурами (ограничение суммы компонентов = 100%)
- 🗺️ Управление технологическими картами (шаги, плановые параметры)
- 📦 Формирование производственных заказов и партий
- ⏱️ Пошаговое выполнение партии с контролем отклонений
- 🧪 Лабораторный контроль (испытания, решения, история)
- 📈 Отчёты по партиям, отклонениям, использованию рецептур
- 📝 Журнал событий и проблем
